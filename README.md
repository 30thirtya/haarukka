# Digital Skills GitHub Test

## Task 1: Your First GitHub Contribution

**Goal:** Successfully contribute to a shared repository.

- Fork the course repository
- Clone your fork using GitHub Desktop
- Create a file named after yourself (e.g. mikko-lehto.txt)
- Commit your changes
- Push to GitHub

### Learning outcomes

- Repository
- Fork
- Clone
- Commit
- Push

## Task 2: Working with Branches

**Goal:** Learn how developers work on features without affecting the main branch.

- Sync/update your fork
- Create a branch called favorite-game
- Edit your file and add your favourite game and genre
- Commit the changes
- Push the branch
- Merge to main

### Learning outcomes

- Branches
- Isolating changes
- Feature workflows
- Multiple pull requests
